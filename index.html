How it works

Six stages. One folder per video.

1 · SCRIPT

You and Claude Code write the narration and list the sources.

2 · SCENES

Claude Code picks scenes and writes the project file.

3 · VOICE

You record or generate a voice file.

4 · CAPTIONS

The kit finds when each sentence is spoken and times the captions.

5 · RENDER

The kit records the video, then adds voice and sound.

6 · REVIEW

You check the result against the quality checklist. You make the final call.

You can start building scenes before you have a voice: the kit estimates the timing from the text.

Is it for you?

Honest limits.

It fits if you

  • want to explain something visually: educational clips, narrated diagrams, short animated explanations;
  • are willing to follow terminal instructions and review what Claude Code produces;
  • work on a Windows PC.

It does not fit if you want

  • guaranteed results of any kind;
  • a finished video in one click, with no review;
  • to work only from a phone;
  • cinematic, photo-realistic animation (the look is stylized: low-poly and line art);
  • a full course on programming or three.js.

Claude Code can make mistakes in facts, spelling and layout. Check every video before you publish. By default, voice timing is an estimate: phrases start on the real pauses in your voice, but single words can be a few tenths of a second off. An optional exact step is included; it needs one extra free program (faster-whisper) on your PC.

What if it does not run on my PC?

Run the doctor command first: it lists what is missing and how to fix it. The troubleshooting guide covers the usual errors, and you can write to us with the error text. If it still does not work for you, ask for the refund within seven days.

How long does a video take to render?

The kit records every picture one by one, so a long video takes longer. A 60-second video is 1,800 pictures. In our test (a 16 GB PC with a graphics card), a 3-second clip (90 pictures) took 11 seconds to record. We have no timing for other PCs.
